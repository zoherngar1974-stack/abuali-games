# ألعاب أبو علي — نموذج أولي

هذا موقع عربي تجريبي يعمل في المتصفح، ويحتوي على:
- لعبة ذاكرة ومطابقة رموز.
- نقاط تجريبية تُحفظ محلياً في المتصفح.
- نموذج طلب سحب تجريبي وسجل محلي للطلبات.
- الدفع الحقيقي وشام كاش غير مفعّلين.

## تشغيل الموقع على هاتف أو كمبيوتر
1. فك ضغط ملف `abuali-games.zip`.
2. افتح مجلد `abuali-games`.
3. افتح ملف `index.html` بمتصفح Chrome أو Firefox أو أي متصفح حديث.

لا يحتاج الموقع إلى تثبيت أو اتصال بخادم لتجربته محلياً.

## نشر مجاني باستخدام GitHub Pages
1. أنشئ حساباً في https://github.com/
2. أنشئ مستودعاً جديداً (Repository) باسم `abuali-games`.
3. ارفع ملف `index.html` إلى جذر المستودع (Add file → Upload files).
4. افتح Settings → Pages.
5. من Build and deployment اختر Deploy from a branch.
6. اختر الفرع `main` والمجلد `/ (root)` ثم Save.
7. انتظر حتى يظهر رابط الموقع في صفحة Pages.

قد تتغير أسماء الخيارات قليلاً حسب واجهة GitHub. لا ترفع كلمات مرور أو مفاتيح API إلى المستودع.

## حدود الأمان المهمة
- النقاط وطلبات السحب تُحفظ في متصفح الجهاز فقط عبر localStorage.
- لا يوجد تسجيل حسابات، ولا قاعدة بيانات مشتركة، ولا لوحة إدارة حقيقية.
- يستطيع المستخدم تعديل النقاط المحلية؛ لذلك لا تستخدم هذه النسخة لتقديم مكافآت مالية.
- لا تدخل رقم محفظة شام كاش حقيقياً في النموذج.
- قبل تشغيل الدفع، يلزم خادم موثوق، وقاعدة بيانات، ومصادقة، وحماية من التلاعب، وموافقة رسمية على تكامل الدفع.
- تحقق من سياسات شبكة الإعلانات قبل ربط الإعلانات بالمكافآت، ومن شروط شام كاش قبل الوعد بالسحب.

## الملفات
- `index.html`: الموقع كاملاً (HTML وCSS وJavaScript).
- `README.md`: دليل التشغيل والنشر.
